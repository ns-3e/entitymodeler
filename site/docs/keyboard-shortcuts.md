On Windows and Linux, use `Ctrl` wherever this page says `⌘`. Single-key shortcuts don't fire while you're typing in a field.

![The command palette listing actions, entities and tabs](/docs/images/command-palette.webp "The command palette (⌘K) finds any entity, attribute or tab and runs any action.")

## Editing

| Shortcut | Action |
| --- | --- |
| `E` | Add an entity in the middle of the view |
| `R` | Relationship tool (press again to leave it) |
| `V` or `Esc` | Select tool; `Esc` also clears the selection |
| `⌫` or `Delete` | Delete the selection |
| `Enter` | Open the inspector for the selection |
| `⌘C` / `⌘V` | Copy and paste entities, also across tabs |
| `⌘D` | Duplicate the selection |
| `⌘A` | Select everything on the diagram |
| `⌘Z` / `⌘⇧Z` (or `⌘Y`) | Undo / redo |
| `⌘S` | Save now |

## View

| Shortcut | Action |
| --- | --- |
| `F` | Fit the diagram to the window |
| `H` | Hide the selection from the diagram |
| `⇧H` | Show all hidden entities |
| `[` | Show or hide the sidebar |
| `]` | Show or hide the inspector |
| `⌘K` | Command palette: jump to an entity, attribute (`order.status`), relationship or tab, or run any action |
| `⌘J` | Ask Claude panel (local mode with Claude Code installed) |

## Mouse and trackpad

| Gesture | Action |
| --- | --- |
| Drag on empty canvas | Box-select |
| `⇧`-click or `⌘`-click | Add to or remove from the selection |
| `Space`+drag, middle-drag, two-finger scroll | Pan |
| Pinch or `⌘`+scroll | Zoom |
| Right-click a selection | Hide, Show only these, Select related, Arrange, Copy, Duplicate, Copy to tab, Color, Delete |
| Right-click empty canvas | Add an entity, note or area where you clicked |
